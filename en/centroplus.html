CentroPlus Connect

Running a school: users, activities, bookings and incident reports, with a desktop app and a REST API.

My role
Solo project
When
May and June 2026, first-year final project
Stack
Java 17, Spring Boot, JavaFX, SQLite and H2

App, Swagger-documented API and 41 test classes

Context

The brief

It was the only project of the year, the end-of-year one for my first-year Programming course. I had a month, from 11 May to 11 June, to build a management app for a school with its database, its API and a user interface.

My role

I built it alone, from the database to the documentation. I used AI for questions and specific parts, but I wrote the code.

  • The databaseThe SQLite schema, models and validation for users, activities, bookings and incident reports.
  • The desktop appActivity list and detail, bookings you can create and cancel, and incident reports with their status.
  • The REST APICRUD for all four resources with Spring Boot, documented with Swagger, plus a management website.

Decisions

Hexagonal architecture in the API

The brief required a hexagonal architecture, and it was my first time using one. The domain (the classes Actividad, Reserva…) knows nothing about the database or HTTP: controllers come in on one side, JPA persistence goes out the other, and in between are the ports, which are interfaces.

To convert between the database entity and the domain model I used MapStruct, which generates those mappings from an interface.

// MapStruct escribe la clase y Spring la inyecta
@Mapper(componentModel = "spring")
public interface ActividadMapper {

    Actividad toDomain(ActividadJpaEntity entity);

    ActividadJpaEntity toEntity(Actividad actividad);
}

Excerpt from adapters/mapper/ActividadMapper.java

Two ways to use it

The JavaFX app is for the people who use the school day to day: browsing activities, booking a place and reporting an issue. The API also serves a website to manage everything from the browser, with nothing to install, including a chart dashboard and export to CSV, JSON and PDF.

Documented and tested

Every endpoint can be tried from the browser with Swagger, and I rewrote its texts to explain the project instead of showing the defaults. Behind it there are 41 test classes with JUnit 5 and Mockito, across the app and the API.

What I learned

Mostly, it was my first look at a lot of things: Spring Boot, JavaFX, hexagonal architecture, Swagger and testing with Mockito.

It went so fast that we barely covered the core of Spring. Now, in second year, we're studying it in depth.
