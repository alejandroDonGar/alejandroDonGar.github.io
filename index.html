Cómo trabajo

  • Commits pequeños que cuentan qué cambió

    Un commit por paso, con un mensaje que explica el cambio y el porqué. En las entregas de Despliegue el profesor revisa el historial, así que lo cuido desde el principio.

    Historial de la web de apuntes

  • Apunto lo que hago mientras lo hago

    Mis README guardan cada comando con la salida real que dio, errores incluidos. Lo que aprendo en clase lo paso a una web de apuntes que cualquiera puede leer.

    Apuntes de 2º DAM

  • Lo doy por terminado cuando pasan las pruebas

    El taller mecánico de Acceso a Datos tenía 90 pruebas con JUnit y no lo entregué hasta verlas todas en verde. En la biblioteca con JPA también cuentan Checkstyle y PMD.

    Código del taller

  • Dejo que las máquinas hagan lo repetitivo

    GitHub Actions compila mis proyectos de Maven y publica el jar. Este CV y la web de apuntes se publican solos cada vez que subo un cambio.

    Ejecuciones de GitHub Actions
