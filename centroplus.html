Contexto

El encargo

Fue el único proyecto del curso, el de final de 1º de Programación. Tenía un mes, del 11 de mayo al 11 de junio, para hacer una aplicación de gestión para un centro educativo con su base de datos, su API y una interfaz.

Mi papel

Lo hice yo solo, de la base de datos a la documentación. Usé IA para resolver dudas y partes concretas, pero el código lo escribí yo.

  • La base de datosEl esquema en SQLite, los modelos y las validaciones de usuarios, actividades, reservas e incidencias.
  • La app de escritorioListado y detalle de actividades, reservas que se crean y se cancelan, e incidencias con su estado.
  • La API RESTEl CRUD de los cuatro recursos con Spring Boot, documentado con Swagger y con una web de gestión.

Decisiones

Arquitectura hexagonal en la API

El enunciado pedía una arquitectura hexagonal, y fue mi primer contacto con ella. El dominio (las clases Actividad, Reserva…) no sabe nada de la base de datos ni de HTTP: los controladores entran por un lado, la persistencia con JPA sale por el otro, y en medio están los puertos, que son interfaces.

Para pasar de la entidad de la base de datos al modelo del dominio usé MapStruct, que genera esas conversiones a partir de una interfaz.

// MapStruct escribe la clase y Spring la inyecta
@Mapper(componentModel = "spring")
public interface ActividadMapper {

    Actividad toDomain(ActividadJpaEntity entity);

    ActividadJpaEntity toEntity(Actividad actividad);
}

Fragmento de adapters/mapper/ActividadMapper.java

Dos formas de usarlo

La app de JavaFX está pensada para el día a día de quien usa el centro: ver actividades, reservar plaza y avisar de una incidencia. La propia API sirve además una web para administrarlo todo desde el navegador, sin instalar nada, con un panel de gráficas y exportación a CSV, JSON y PDF.

Documentada y con pruebas

Cada endpoint se puede probar desde el navegador con Swagger, y adapté sus textos para que expliquen el proyecto en lugar de mostrar los que vienen por defecto. Detrás hay 41 clases de test con JUnit 5 y Mockito, entre la app y la API.
